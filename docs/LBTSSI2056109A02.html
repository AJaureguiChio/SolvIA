3. Desarrollo Técnico y Fundamento de Inteligencia Artificial

3.1. Microservicio de Verificación Facial (FastAPI + FaceNet)

El servicio de IA reside en services/ai-service y procesa solicitudes mediante una arquitectura de dos redes neuronales profundas encadenadas:

  • MTCNN (Multi-task Cascaded Convolutional Networks): Localiza rostros en el frame recibido, evalúa la calidad visual y alinea la cara a un recorte estándar de 160×160 píxeles. Filtra imágenes con más de un rostro o con baja resolución (menor a 80 px).
  • Inception-ResNet-v1 (Pesos VGGFace2): Red convolucional profunda que proyecta el rostro en un espacio euclidiano de 512 dimensiones, generando el vector de características (embedding).
Normalización L2 y Similitud Coseno:
v̂ = v / ||v||₂    |    Similitud(a, b) = a · b  ∈ [-1, 1]

Para cada usuario registrado se conserva una galería de vectores de referencia (estrategia "Best of N" con k=4 fotos). La verificación biométrica 1:1 calcula el puntaje máximo:

Score = maxj { Similitud(probe, galleryj) }   ⇒   match = (Score ≥ MATCH_THRESHOLD)

3.2. Calibración Empírica de Umbral (Script de Experimento)

A través de scripts/experiment.py se cuantificó la separación entre clases utilizando muestras genuinas e impostoras:

  • Comparación Intra-clase (Tu vs Tu): Similitudes observadas entre 0.65 y 0.88.
  • Comparación Inter-clase (Tu vs Otros): Similitudes observadas entre 0.12 y 0.28.
  • Margen de separación (Gap): Superior a 0.35, lo que valida la selección de un MATCH_THRESHOLD = 0.40 con cero falsas aceptaciones (FAR ≈ 0%).

3.3. Detección Facial en Navegador (Frontend)

Se desarrolló el componente de captura de video que interactúa con la cámara del dispositivo:

  • Acceso nativo mediante navigator.mediaDevices.getUserMedia.
  • Encuadre asistido con máscara elíptica de posicionamiento.
  • Captura de snapshot a resolución nativa, serializado a Base64 listo para transmisión.

3.4. Infraestructura de Base de Datos y Backend (Neon PostgreSQL)

Se estableció la conexión del backend (NestJS) a la base de datos PostgreSQL hospedada en Neon Serverless, integrando el esquema relacional final con tablas de usuarios, roles de analista, deudores, movimientos y planes de pago.
